Comprehensive guide to the technical implementation of the Return to Work Portal for La Rose Noire.

1. Overview

The Return to Work Portal is a web-based application designed for La Rose Noire to streamline the process of employees returning to work after an absence (such as sick leave). It eliminates manual paper forms by providing a digital workflow for filing, supervisor approval, and nurse health clearance.

Tech Stack

  • Frontend: HTML5, Tailwind CSS, JS
  • Backend: PHP (Vanilla)
  • Database: SQL Server

Databases

  • LRNPH_E (Main Data)
  • LRNPH (Users)
  • LRNPH_OJT (Emp Data)

Server Setup

  • Host: 10.2.0.9 (DB)
  • Port: 1433
  • Env: Apache/XAMPP

Table: lrnph_users

Read-only view for Authentication (DB: LRNPH)

  • username (Biometrics ID)
  • password (Bcrypt hashed password)

Used in auth/authenticate.php to verify user credentials during login.

Table: lrn_master_list

Read-only view for Employee Details (DB: LRNPH_E & LRNPH_OJT)

  • BiometricsID (Joins to username)
  • EmployeeID (Used for Role mapping & ID photos)
  • FirstName, LastName
  • Department, PositionTitle

Provides user context post-login and allows supervisor/employee lookups.

4. Process Flow

User Roles & Access Control

Access to specific modules is determined during login at auth/authenticate.php.

Employee Level

Any valid user. Navigates to pages/index.php to file an RTW application and track its history.

Approver Level

Hardcoded mapping of authorized EmployeeIDs. Accesses pages/dashboard.php.

Nurse Level

Users with `PositionTitle` as 'clinic assistant' or 'company nurse'. Accesses pages/nurse_dashboard.php.
